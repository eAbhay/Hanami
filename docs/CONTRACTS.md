# Hanami — component contracts

Hanami is a tray-only Windows live-wallpaper app. A thin C# host (WPF, .NET 10) does the
Windows work; everything visual is HTML/JS rendered in WebView2. This file is the source of
truth for how the pieces talk to each other. Change it first, then the code.

```
Hanami.exe (C# host)
 ├─ tray icon, single instance, startup registration, install/update flow
 ├─ per-monitor wallpaper windows (WebView2) parented behind the desktop icons
 ├─ cursor/click polling → wallpaper pages
 ├─ power / fullscreen / lock monitoring → per-monitor mode
 ├─ library on disk (import, delete, thumbnails), export/import packs
 └─ settings window (WebView2) ⇄ JSON bridge
web/
 ├─ shared/effects.js      particle engine, used by wallpaper AND settings preview
 ├─ wallpaper/             the page shown behind the icons (one instance per monitor)
 └─ settings/              the settings UI
```

## Virtual hosts

WebView2 maps folders to fake HTTPS origins:

| Origin | Folder |
|---|---|
| `https://app.hanami/` | the `web/` folder (`/shared/…`, `/wallpaper/…`, `/settings/…`) |
| `https://library.hanami/` | `<installDir>/Library/` |

Pages must use relative or these absolute URLs only. No CDNs — the app must work offline.
Both hosts are mapped with `CoreWebView2HostResourceAccessKind.Allow`, so `app.hanami` pages can
load `library.hanami` media with `crossOrigin="anonymous"` and still export canvas frames
(the settings UI relies on this for thumbnails).

## On-disk layout (install root, chosen by the user on first run)

```
<installDir>/
  Hanami.exe
  config/settings.json
  Library/
    wallpapers/<id>/manifest.json
    wallpapers/<id>/media.<ext>        video (mp4/webm) or image (jpg/png/webp)
    wallpapers/<id>/thumb.jpg          generated by the settings UI, may be missing
  app/web/                             extracted copy of web/ (overwritten on version change)
```

`manifest.json`:

```json
{ "id": "k3j2h1", "name": "Sakura river", "type": "video", "file": "media.mp4",
  "createdAt": "2026-11-01T10:00:00Z", "width": 1920, "height": 1080, "durationSec": 12.5,
  "hasThumbnail": true }
```

Built-in wallpapers are not on disk. Their ids are `builtin:<scene>` and they are rendered
procedurally by the wallpaper page. Scenes: `twilight`, `dawn`, `night`.

## Shared types

```ts
type Mode = "full" | "reduced" | "paused";
// full    — video plays, effects at fpsCap
// reduced — video (and built-in scene) frozen on its current frame, effects at min(fpsCap, 30)
// paused  — everything frozen, no animation frames requested at all

type EffectConfig = {
  preset: "none" | "sakura" | "snow" | "leaves" | "fireflies" | "rain" | "sparkles";
  density: number;            // 0.1 – 3, default 1   (multiplier on the preset's base count)
  speed: number;              // 0.2 – 3, default 1
  size: number;               // 0.5 – 2, default 1
  opacity: number;            // 0 – 1,  default 1
  wind: number;               // -1 – 1, default 0 (constant sideways drift)
  interaction: "none" | "repel" | "attract" | "wind";   // default "repel"
  interactionStrength: number; // 0 – 2, default 1
  interactionRadius: number;   // CSS px, 40 – 400, default 160
  clickBurst: boolean;         // default true
};

type WallpaperRef = {           // what the host sends to a wallpaper page
  id: string;
  name: string;
  type: "video" | "image" | "builtin";
  src?: string;                 // https://library.hanami/wallpapers/<id>/media.mp4 (video/image)
  scene?: "twilight" | "dawn" | "night";   // builtin only
  fit: "cover" | "contain" | "fill";        // default "cover"
};

type WallpaperInfo = {          // what the settings UI lists
  id: string; name: string; type: "video" | "image" | "builtin";
  builtin: boolean;
  src?: string;                 // library.hanami URL of the media (not for builtin)
  thumbnail?: string | null;    // library.hanami URL, or null if not generated yet
  sizeBytes: number;            // 0 for builtin
  width?: number; height?: number; durationSec?: number;
  createdAt?: string;
};
```

## Host → wallpaper page

Page URL: `https://app.hanami/wallpaper/index.html?monitor=<monitorKey>`.
Messages arrive via `window.chrome.webview.addEventListener("message", e => e.data)`
(already parsed objects).

| Message | Meaning |
|---|---|
| `{type:"config", wallpaper: WallpaperRef \| null, effect: EffectConfig, fpsCap: number, mode: Mode}` | Full (re)configuration. Sent after `ready` and whenever anything changes. `wallpaper: null` → plain dark background. |
| `{type:"mode", mode: Mode}` | Mode change only. |
| `{type:"pointer", x, y, inside}` | Cursor in CSS px relative to this monitor's top-left. `inside:false` when the cursor is on another monitor (effects should relax back). Sent at up to 60 Hz, only on change. |
| `{type:"click", x, y, button}` | A click that landed on the desktop surface of this monitor. `button`: `"left"` \| `"right"`. The page only bursts on left clicks (right opens the desktop menu). |

Page → host: `window.chrome.webview.postMessage(obj)`

| Message | Meaning |
|---|---|
| `{type:"ready"}` | Page loaded; host replies with `config`. |
| `{type:"mediaError", wallpaperId, message}` | Video/image failed to load or decode. |
| `{type:"dismiss", input}` | Screensaver pages only (`&screensaver=1`): a key press or mouse click asked to end it. |

The page must also run standalone in a normal browser for development
(`web/wallpaper/index.html?dev`): when `window.chrome?.webview` is missing, use real mouse
events for pointer/click and a built-in dev config (and a small dev panel to switch preset/scene).

## Settings bridge

Request: `window.chrome.webview.postMessage({id, method, params})`
Response: host posts `{id, result}` or `{id, error: "message"}`.
Events: host posts `{event: "<name>", data}`.

| Method | Params | Result |
|---|---|---|
| `getState` | – | `State` |
| `updateSettings` | `Partial<Settings>` (deep-merged) | `State` |
| `setAssignment` | `{monitorKey: string \| "*", wallpaperId?: string, effect?: Partial<EffectConfig>}` | `State` |
| `importMedia` | – (host opens a file dialog, multi-select, copies files into the library) | `{imported: WallpaperInfo[]}` or `{cancelled: true}` |
| `renameWallpaper` | `{id, name}` | `State` |
| `deleteWallpaper` | `{id}` (never builtin) | `State` |
| `saveThumbnail` | `{id, dataUrl, width?, height?, durationSec?}` (JPEG data URL) | `{ok: true}` |
| `setPaused` | `{paused: boolean}` | `State` |
| `openLibraryFolder` | – | `{ok: true}` |
| `getExportItems` | – | `ExportItem[]` |
| `exportPack` | `{ids: string[], includeSettings: boolean}` (host opens save dialog) | `{path}` or `{cancelled: true}` |
| `importPack` | – (host opens open dialog) | `{imported: number}` or `{cancelled: true}` |
| `previewScreensaver` | – (shows the screensaver now, ignoring idle time and power source; ends on input as usual) | `{ok: true}` |
| `quit` | – | – |

Events: `stateChanged` (data: `State`), `progress` (data: `{task: "import"\|"export"\|"importPack", done: number, total: number, label: string}`; `done === total` means finished).

```ts
type ExportItem = { id: string; kind: "wallpaper" | "settings"; name: string; sizeBytes: number;
                    thumbnail?: string | null };

type Settings = {
  sameOnAllMonitors: boolean;                       // default true
  assignments: Record<string, { wallpaperId: string | null; effect: EffectConfig }>;
  // key "*" = default for every monitor; other keys = monitorKey overrides (used when !sameOnAllMonitors)
  power: {
    onAC: Mode;                 // default "full"
    onBattery: Mode;            // default "paused"
    lowBattery: Mode;           // default "paused"
    lowBatteryThreshold: number;// percent, default 20
    energySaver: Mode;          // default "reduced"  (Windows Energy/Battery Saver on)
    whenMaximized: Mode;        // default "paused"   (a maximized window on that monitor)
    whenFullscreen: Mode;       // default "paused"   (a fullscreen app/game on that monitor)
  };
  performance: { fpsCap: number; batteryFpsCap: number };   // defaults 60 / 30
  screensaver: {
    enabled: boolean;           // default true
    idleMinutes: number;        // 1 – 120, default 2
    wallpaperId: string | null; // null = same wallpaper + effect as each monitor's desktop
    requireSignIn: boolean;     // default false — lock Windows when the screensaver ends
    stopAfterHours: number;     // 0 = never (default); after this, hide it and let Windows' timers take over
  };
  startWithWindows: boolean;    // default true
  paused: boolean;              // manual pause from tray/UI, default false
};

type MonitorInfo = { key: string; name: string; isPrimary: boolean;
                     width: number; height: number; scale: number };   // physical px, DPI scale

type State = {
  version: string;
  installDir: string;
  libraryDir: string;
  settings: Settings;
  monitors: MonitorInfo[];
  modes: Record<string, { mode: Mode; reason: string }>;   // effective mode per monitorKey
  power: { onBattery: boolean; batteryPercent: number | null; energySaver: boolean };
  wallpapers: WallpaperInfo[];                              // builtins first
  screensaver: {
    active: boolean;            // showing right now
    status: string;             // human-readable, e.g. "Starts after 2 min idle", "Off on battery",
                                // "Another app is keeping the screen on", "Showing"
    windowsDisplayOffMinutes: number | null;  // Windows' plugged-in "turn off screen after" (null = never)
    windowsSleepMinutes: number | null;       // Windows' plugged-in "sleep after" (null = never)
  };
};
```

Effective mode per monitor = the most restrictive (`paused` < `reduced` < `full`) of:
manual pause, maximized/fullscreen rule for that monitor, battery rule (`lowBattery` when
on battery and at/below threshold, else `onBattery`; `onAC` when plugged in), energy-saver rule.
A paused wallpaper is never hidden (it keeps its frozen frame, so Win+D shows no flash of the
stock wallpaper); only the screensaver hides the desktop wallpapers (hidden + suspended).
**Idle freeze:** while the user is idle within 5 s of the earlier of the screensaver start
(enabled, plugged in) and Windows' display-off timeout for the current power source, every
monitor is capped at `reduced` with reason `Idle` (video frozen, effects keep moving), because a
playing `<video>` holds a Windows display-required request that blocks both. After the
screensaver ends on its own (stop-after, unplug) the cap stays until the next real input.

### Screensaver behaviour

Plugged in only. After `idleMinutes` without keyboard/mouse input the host covers every monitor
with a topmost fullscreen window showing the wallpaper page (`…/wallpaper/index.html?monitor=<key>&screensaver=1`,
always in `full` mode, cursor hidden, with a glass clock and date) and holds a Windows
display-required + system-required power request, so the screen stays on and the PC does not
idle-sleep. Only a key press or mouse click ends it — moving the mouse does not (and it locks
Windows first if `requireSignIn`). The page has keyboard focus and posts
`{type:"dismiss", input:"key"|"click"}` to the host; if Windows refused focus, the host treats
input that didn't move the cursor as a key press.
It does not start (status explains why) when: disabled, on battery, session locked, a fullscreen
app is running, or another app already holds a display request (video playback, calls).
It ends on unplug, lock, sleep, or after `stopAfterHours`. The idle count restarts after waking.
The power request belongs to the Hanami process, so quitting Hanami restores Windows' own
screen-off and sleep timers; Hanami never changes Windows power settings. Lid close always
follows Windows (apps cannot block it).

The settings UI must run standalone in a browser (`web/settings/index.html`) using
`web/settings/mock-bridge.js` when `window.chrome?.webview` is missing.

## `web/shared/effects.js` (ES module)

```js
export const PRESETS;          // [{id, name, description}] — "none" included
export const DEFAULT_EFFECT;   // EffectConfig with the defaults above, preset "sakura"
export class EffectsEngine {
  constructor(canvas, config = DEFAULT_EFFECT)
  setConfig(partialConfig)     // merge; re-seed particles only if preset/density changed
  setPointer(x, y, inside = true)   // CSS px relative to the canvas
  click(x, y)                  // burst, if config.clickBurst
  setFpsCap(fps)
  start()                      // requestAnimationFrame loop, honours fpsCap
  stop()                       // cancels the loop entirely
  resize()                     // sizes the backing store to clientWidth/Height × devicePixelRatio
  destroy()
}
```
