# Hanami — component contracts

Hanami is a tray-only Windows live-wallpaper app. A thin C# host (WPF, .NET 10) does the
Windows work; everything visual is HTML/JS rendered in WebView2. This file is the source of
truth for how the pieces talk to each other. Change it first, then the code.

```
Hanami.exe (C# host)
 ├─ tray icon, single instance, startup registration, install/update flow
 ├─ per-monitor wallpaper windows (WebView2) parented behind the desktop icons
 ├─ cursor/click polling → wallpaper pages
 ├─ power / fullscreen / lock monitoring → per-monitor mode
 ├─ library on disk (import, delete, thumbnails), export/import packs
 └─ settings window (WebView2) ⇄ JSON bridge
web/
 ├─ shared/effects.js      particle engine, used by wallpaper AND settings preview
 ├─ wallpaper/             the page shown behind the icons (one instance per monitor)
 └─ settings/              the settings UI
```

## Virtual hosts

WebView2 maps folders to fake HTTPS origins:

| Origin | Folder |
|---|---|
| `https://app.hanami/` | the `web/` folder (`/shared/…`, `/wallpaper/…`, `/settings/…`) |
| `https://library.hanami/` | `<installDir>/Library/` |

Pages must use relative or these absolute URLs only. No CDNs — the app must work offline.
Both hosts are mapped with `CoreWebView2HostResourceAccessKind.Allow`, so `app.hanami` pages can
load `library.hanami` media with `crossOrigin="anonymous"` and still export canvas frames
(the settings UI relies on this for thumbnails).

## On-disk layout (install root, chosen by the user on first run)

```
<installDir>/
  Hanami.exe
  config/settings.json
  Library/
    wallpapers/<id>/manifest.json
    wallpapers/<id>/media.<ext>        video (mp4/webm) or image (jpg/png/webp)
    wallpapers/<id>/thumb.jpg          generated by the settings UI, may be missing
    fonts/<id>.<ttf|otf|woff|woff2>    imported clock fonts
    pets/<packId>/manifest.json        a Shimeji image set: {id, name, createdAt, frameWidth, frameHeight,
                                       frames: number[]}  (id = "pet-" + 8 hex; frames = which shime numbers exist)
    pets/<packId>/img/shime<N>.png     N in 1–46, all frames of a pack the same size (≤ 1024 px)
  app/web/                             extracted copy of web/ (overwritten on version change)
```

`manifest.json`:

```json
{ "id": "k3j2h1", "name": "Sakura river", "type": "video", "file": "media.mp4",
  "createdAt": "2026-11-01T10:00:00Z", "width": 1920, "height": 1080, "durationSec": 12.5,
  "hasThumbnail": true }
```

Built-in wallpapers are not on disk. Their ids are `builtin:<scene>` and they are rendered
procedurally by the wallpaper page. Scenes: `twilight`, `dawn`, `night`.

## Shared types

```ts
type Mode = "full" | "reduced" | "paused";
// full    — video plays, effects at fpsCap
// reduced — video (and built-in scene) frozen on its current frame, effects at min(fpsCap, 30)
// paused  — everything frozen, no animation frames requested at all

type PresetId = "none" | "sakura" | "snow" | "leaves" | "fireflies" | "rain" | "sparkles" | "embers";

// Defaults below are the generic ones; each preset has its own (PRESET_DEFAULTS in
// web/shared/effects.js — the only place defaults live; the host has none).
type EffectConfig = {
  preset: PresetId;
  density: number;            // 0.1 – 3, default 1   (multiplier on the preset's base count)
  speed: number;              // 0.2 – 3, default 1
  size: number;               // 0.5 – 2, default 1
  opacity: number;            // 0 – 2,  default 1. Up to 1 it multiplies each particle's alpha;
                              // above 1 it lifts faint particles without clipping bright ones:
                              // a' = 1 − (1 − a)^opacity
  flicker: number;            // 0 – 1, per-preset default (fireflies 0.5, sparkles 0.5, embers 0.4,
                              // others 0 and unused). Depth of the pulse/twinkle/flicker; 1 = full depth
  wind: number;               // -1 – 1, default 0 (constant sideways drift)
  interaction: "none" | "repel" | "attract" | "wind";   // default "repel"
  interactionStrength: number; // 0 – 2, default 1
  interactionRadius: number;   // CSS px, 40 – 400, default 160
  clickBurst: boolean;         // default false
};
type EffectTuning = Omit<EffectConfig, "preset">;

type WallpaperRef = {           // what the host sends to a wallpaper page
  id: string;
  name: string;
  type: "video" | "image" | "builtin";
  src?: string;                 // https://library.hanami/wallpapers/<id>/media.mp4 (video/image)
  scene?: "twilight" | "dawn" | "night";   // builtin only
  fit: "cover" | "contain" | "fill";        // default "cover"
};

type WallpaperInfo = {          // what the settings UI lists
  id: string; name: string; type: "video" | "image" | "builtin";
  builtin: boolean;
  src?: string;                 // library.hanami URL of the media (not for builtin)
  thumbnail?: string | null;    // library.hanami URL, or null if not generated yet
  sizeBytes: number;            // 0 for builtin
  width?: number; height?: number; durationSec?: number;
  createdAt?: string;
};
```

## Host → wallpaper page

Page URL: `https://app.hanami/wallpaper/index.html?monitor=<monitorKey>`.
Messages arrive via `window.chrome.webview.addEventListener("message", e => e.data)`
(already parsed objects).

| Message | Meaning |
|---|---|
| `{type:"config", wallpaper: WallpaperRef \| null, effect: {preset} & Partial<EffectTuning>, fpsCap: number, mode: Mode}` | Full (re)configuration. Sent after `ready` and whenever anything changes. `wallpaper: null` → plain dark background. `effect` is the preset plus only the user's overrides for it; the page fills every missing key from `PRESET_DEFAULTS[preset]`. |
| `{type:"mode", mode: Mode}` | Mode change only. |
| `config.clock` | Screensaver pages only (`&screensaver=1`): `{x, y, size, showDate, dateFont, font: {id, family, src?} \| null}` — the `Settings.screensaver.clock` values with `font` resolved (`src` = `https://library.hanami/fonts/<file>` for imported fonts; null = Tilt Warp). The page centres the time on `(x·width, y·height)`, clamped so everything stays on screen, and scales the glass filter with `size`. |
| `{type:"pointer", x, y, inside}` | Cursor in CSS px relative to this monitor's top-left. `inside:false` when the cursor is on another monitor (effects should relax back). Sent at up to 60 Hz, only on change. |
| `{type:"click", x, y, button}` | A click that landed on the desktop surface of this monitor. `button`: `"left"` \| `"right"`. The page only bursts on left clicks (right opens the desktop menu). |

Page → host: `window.chrome.webview.postMessage(obj)`

| Message | Meaning |
|---|---|
| `{type:"ready"}` | Page loaded; host replies with `config`. |
| `{type:"mediaError", wallpaperId, message}` | Video/image failed to load or decode. |
| `{type:"fontError", font, message}` | Screensaver pages only: the clock font (`font` = the setting string) failed to load; the page shows Tilt Warp. The host logs it. |
| `{type:"dismiss", input}` | Screensaver pages only (`&screensaver=1`): a key press or mouse click asked to end it. |

The page must also run standalone in a normal browser for development
(`web/wallpaper/index.html?dev`): when `window.chrome?.webview` is missing, use real mouse
events for pointer/click and a built-in dev config (and a small dev panel to switch preset/scene).

## Settings bridge

Request: `window.chrome.webview.postMessage({id, method, params})`
Response: host posts `{id, result}` or `{id, error: "message"}`.
Events: host posts `{event: "<name>", data}`.

```ts
type PetPackInfo = {
  id: string; name: string;
  preview: string;              // https://library.hanami/pets/<id>/img/shime1.png
  frames: number;               // how many shime images the pack has
  sizeBytes: number; frameWidth: number; frameHeight: number;
  capabilities: { climb: boolean; ceiling: boolean; sit: boolean; sleep: boolean };   // from which frames exist
};
// Import accepts only shime<N>.png (N 1–46) found in the chosen folder, its img/, one level deeper or img/<Name>
// (a zip may hold several characters: each becomes its own pack, named after its folder). Required: shime1–10
// (stand, walk, fall, everything used while dragged); missing climb (12–14), ceiling (23–25), sit (11) or sleep
// (21) frames only switch that capability off. Limits: 2 MB per PNG, 40 MB per pack, 1024 px, each PNG must
// decode, all frames one size. Zip entry paths are never used to write files. A .hanamipack carries pets/<id>/…
// and re-validates them on import.

type FontInfo = { id: string; name: string; src: string; sizeBytes: number };
// src = https://library.hanami/fonts/<id>; id = the sanitized file name (no separators, no "..",
// extension one of .ttf .otf .woff .woff2). Packs exported with settings carry the selected font as fonts/<id>.
```

Events: `stateChanged` (data: `State`), `progress` (data: `{task: "import"\|"export"\|"importPack", done: number, total: number, label: string}`; `done === total` means finished).

```ts
type ExportItem = { id: string; kind: "wallpaper" | "pet" | "settings"; name: string; sizeBytes: number;
                    thumbnail?: string | null };
// A wallpaper item carries that wallpaper's look (looks/<id>.json in the pack) even when settings are not
// included; importing restores it unless this PC already has a look for that wallpaper.

type Settings = {
  settingsVersion: number;                          // 3. Missing = 1; one-time migrations run on load
  // v1 → v2: drop clickBurst from every effects[preset] override (it became off by default and old
  // files stored whole effect objects, so the stored value was the old default, not a choice)
  // v2 → v3: the effect (assignments[key].effectPreset) and the screensaver's effect and clock moved into
  // per-wallpaper looks. For every assignment {W, P}: looks[W].desktop.effectPreset = P; the old
  // screensaver effect and clock go into the screensaver look of every wallpaper currently used as
  // the screensaver background. Nothing visible changes (the global effects tuning still applies).
  // The legacy fields are read once and never written back.
  sameOnAllMonitors: boolean;                       // default true
  assignments: Record<string, { wallpaperId: string | null; darkWallpaperId: string | null }>;
  // key "*" = default for every monitor; other keys = monitorKey overrides (used when !sameOnAllMonitors).
  // darkWallpaperId is the slot's dark-mode wallpaper (null = use wallpaperId, so a slot is never empty);
  // it only matters while theme.split is on.
  theme: {
    split: boolean;             // default false: one wallpaper per slot, the app looks as before
    mode: "system" | "light" | "dark";   // default "system" = follow Windows' apps theme (Settings → Colors)
  };
  // Which wallpaper a slot shows = split && activeTheme == "dark" && darkWallpaperId != null ? darkWallpaperId
  // : wallpaperId. The screensaver's "same as desktop" means the desktop wallpaper for the active theme.
  // Everything else (effect, tuning, clock) is the shown wallpaper's look, so the theme only picks the wallpaper.
  effects: Partial<Record<PresetId, Partial<EffectTuning>>>;
  // The effect defaults: the user's tuning per effect, the starting point for wallpapers that haven't
  // tuned that effect themselves ("Use as default for <Effect>" in the drawer writes here). Missing
  // keys fall back to PRESET_DEFAULTS. Files from before this shape (assignments[key].effect = a
  // whole EffectConfig) are migrated on load.
  looks: Record<string /* wallpaperId */, {
    desktop: { effectPreset: PresetId;                       // default "sakura"
               tuning: Partial<Record<PresetId, Partial<EffectTuning>>> };   // this wallpaper's own sliders, per preset
    screensaver: { effectPreset: PresetId | null;            // null = same as desktop, sharing its tuning
                   tuning: Partial<Record<PresetId, Partial<EffectTuning>>>;  // used only with an own effect
                   clock: ClockSettings };
  }>;
  // Every wallpaper remembers its own look, so switching wallpapers (or screensaver backgrounds) back
  // and forth brings each one's effect, tuning and clock back. Tuning layers, lowest first:
  // PRESET_DEFAULTS[preset] → effects[preset] → the look's own tuning[preset]. A wallpaper selected
  // for the first time copies the look of the wallpaper it replaces on that monitor (desktop) or the
  // previous screensaver background's screensaver look. A wallpaper with no stored look shows the
  // built-in default (sakura, "same as desktop", default clock). Deleting a wallpaper deletes its
  // look; ids of unknown wallpapers are dropped on load. The same wallpaper on two monitors shares one look.
  power: {
    onAC: Mode;                 // default "full"
    onBattery: Mode;            // default "paused"
    lowBattery: Mode;           // default "paused"
    lowBatteryThreshold: number;// percent, default 20
    energySaver: Mode;          // default "reduced"  (Windows Energy/Battery Saver on)
    whenMaximized: Mode;        // default "paused"   (a maximized window on that monitor)
    whenFullscreen: Mode;       // default "paused"   (a fullscreen app/game on that monitor)
  };
  performance: { fpsCap: number; batteryFpsCap: number };   // defaults 60 / 30
  screensaver: {
    enabled: boolean;           // default true
    idleMinutes: number;        // 1 – 120, default 2
    wallpaperId: string | null; // null = same wallpaper as each monitor's desktop (and its look)
    darkWallpaperId: string | null; // dark-mode background; null = use wallpaperId. Only with an own wallpaperId
    requireSignIn: boolean;     // default false — lock Windows when the screensaver ends
    stopAfterHours: number;     // 0 = never (default); after this, hide it and let Windows' timers take over
  };
  pets: {
    enabled: boolean;           // default true ("Show pets")
    items: { id: string; packId: string }[];   // pets out; the same pack may appear more than once; max 8
    scale: number;              // 0.5 – 2, default 1
    climbWindows: boolean;      // default true
    activity: "calm" | "normal" | "lively";    // default "normal"
  };
  // Items whose pack is gone are dropped on load; bad ids and duplicate item ids are repaired.
  startWithWindows: boolean;    // default true
  paused: boolean;              // manual pause from tray/UI, default false
};

type ClockSettings = {          // the screensaver clock of one wallpaper (looks[id].screensaver.clock)
  x: number; y: number;         // centre of the TIME as a fraction of the monitor, 0–1; default 0.5, 0.31
  size: number;                 // 0.5 – 1.6, default 1
  font: string | null;          // null = bundled Tilt Warp · "system:<family>" = an installed Windows font ·
                                // "library:<file>" = an imported font in Library/fonts/ (a missing one shows Tilt Warp)
  dateFont: "system" | "same";  // "same" = the date uses the clock's font; default "system" (Segoe UI)
  showDate: boolean;            // default true
};

type MonitorInfo = { key: string; name: string; isPrimary: boolean;
                     width: number; height: number; scale: number };   // physical px, DPI scale

type State = {
  version: string;
  installDir: string;
  libraryDir: string;
  settings: Settings;
  monitors: MonitorInfo[];
  modes: Record<string, { mode: Mode; reason: string }>;   // effective mode per monitorKey
  power: { onBattery: boolean; batteryPercent: number | null; energySaver: boolean };
  wallpapers: WallpaperInfo[];                              // builtins first
  petPacks: PetPackInfo[];
  theme: { active: "light" | "dark"; windows: "light" | "dark" };   // the theme in use (mode applied) · Windows' own
  screensaver: {
    active: boolean;            // showing right now
    status: string;             // human-readable, e.g. "Starts after 2 min idle", "Off on battery",
                                // "Another app is keeping the screen on", "Showing"
    windowsDisplayOffMinutes: number | null;  // Windows' plugged-in "turn off screen after" (null = never)
    windowsSleepMinutes: number | null;       // Windows' plugged-in "sleep after" (null = never)
  };
};
```

Effective mode per monitor = the most restrictive (`paused` < `reduced` < `full`) of:
manual pause, maximized/fullscreen rule for that monitor, battery rule (`lowBattery` when
on battery and at/below threshold, else `onBattery`; `onAC` when plugged in), energy-saver rule.
The host composes what a page shows: `config.effect` = preset + the layered tuning of the look of the
wallpaper shown there (desktop look on the desktop; on the screensaver, the screensaver background's
screensaver effect, or its desktop effect and tuning when "same as desktop"), `config.clock` = that
wallpaper's clock.
A paused wallpaper is never hidden (it keeps its frozen frame, so Win+D shows no flash of the
stock wallpaper); only the screensaver hides the desktop wallpapers (hidden + suspended).
**Idle freeze:** while the user is idle within 5 s of the earlier of the screensaver start
(enabled, plugged in) and Windows' display-off timeout for the current power source, every
monitor is capped at `reduced` with reason `Idle` (video frozen, effects keep moving), because a
playing `<video>` holds a Windows display-required request that blocks both. After the
screensaver ends on its own (stop-after, unplug) the cap stays until the next real input.

### Screensaver behaviour

Plugged in only. After `idleMinutes` without keyboard/mouse input the host covers every monitor
with a topmost fullscreen window showing the wallpaper page (`…/wallpaper/index.html?monitor=<key>&screensaver=1`,
always in `full` mode, cursor hidden, with a glass clock and date) and holds a Windows
display-required + system-required power request, so the screen stays on and the PC does not
idle-sleep. Only a key press or mouse click ends it — moving the mouse does not (and it locks
Windows first if `requireSignIn`). The page has keyboard focus and posts
`{type:"dismiss", input:"key"|"click"}` to the host; if Windows refused focus, the host treats
input that didn't move the cursor as a key press.
It does not start (status explains why) when: disabled, on battery, session locked, a fullscreen
app is running, or another app already holds a display request (video playback, calls).
It ends on unplug, lock, sleep, or after `stopAfterHours`. The idle count restarts after waking.
The power request belongs to the Hanami process, so quitting Hanami restores Windows' own
screen-off and sleep timers; Hanami never changes Windows power settings. Lid close always
follows Windows (apps cannot block it).

### Desktop pets

Pets are native, not web: one small borderless WPF window per pet (`PetWindow`: transparent, topmost,
`WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`, never focused, not in the taskbar), placed with `SetWindowPos` in physical
pixels. A layered window hit-tests on pixel alpha, so clicks on the transparent parts reach the app below. Frames face
LEFT and are mirrored when a pet faces right; each pose's anchor (the pet's feet on a floor, its hands on a wall or
ceiling) sits on the pet's position. The simulation (`Core/Pets/World`, `PetBrain`) is pure, in physical pixels, stepped
at 25 Hz (`ShimejiFrames.TickRate`), and uses the frame table in `ShimejiFrames` (from Shimeji-ee's default
`actions.xml`; the packs' own action scripts are never run).

- **World** = each monitor's work area (floor = top of the taskbar, ceiling, side walls except where another monitor
  continues them) and, when `pets.climbWindows`, the visible application windows (`WindowScan`: visible, not
  minimized/cloaked, titled, not a tool window, overlay, shell window or ours, ≥ 120×60, frame bounds without the
  invisible resize border). A window's top edge is a floor and its sides are walls, only where no window in front
  covers them; maximized and fullscreen windows give no edges but still hide what is behind them. Rebuilt on
  WinEvent hooks (location change, move/size, minimize, destroy/hide, foreground; at most once per tick), every
  500 ms, and when the work areas change (checked every 2 s, also after resume).
- **Behaviour**: stand, walk, run, sit, lie, sleep (after a long untouched stretch), climb screen edges and window
  sides, hang from and climb along the ceiling, fall (gravity 2 px/tick², terminal ≈ 20), land (bounce frames), react
  to a click (hearts rise inside the pet window), sometimes walk or run to the cursor when it is on the floor's level,
  and sprawl dizzily after being carried around for 5+ seconds. Only abilities the pack's frames allow are used.
  A pet on a window is carried when it moves and falls when the window is minimized, closed or covered. Pets never
  move, resize or focus the user's windows. Mouse: press and drag (> 4 px) picks a pet up (the cursor holds its
  anchor), release throws it with the last ~80 ms of cursor velocity, a click without moving reacts, right-click opens
  Sit · Sleep · Hide pets · Pet settings.
- **Visibility**: always on top of apps; hidden while a fullscreen app covers their monitor, while the screensaver
  shows and while Windows is locked; "Hide pets" (tray or pet menu) hides them for the session only. They follow the
  power rules without the maximized/fullscreen rules: `paused` freezes them on their current frame (and they can't be
  picked up), `reduced` redraws at most every other tick. Pets never multiply; at most 8.
- A pet is drawn at `pets.scale` × its monitor's DPI scale (resized explicitly when it crosses to another monitor).

The settings UI must run standalone in a browser (`web/settings/index.html`) using
`web/settings/mock-bridge.js` when `window.chrome?.webview` is missing.

## `web/shared/effects.js` (ES module)

```js
export const PRESETS;          // [{id, name, description, flicker?}] — "none" included.
                               // flicker: true = the preset uses the `flicker` key (the drawer shows
                               // its slider only then)
export const DEFAULT_EFFECT;   // EffectConfig with the generic defaults above, preset "sakura"
export const PRESET_DEFAULTS;  // Record<PresetId, EffectConfig> — each preset's own defaults
export class EffectsEngine {
  constructor(canvas, config = DEFAULT_EFFECT)   // gaps filled from PRESET_DEFAULTS[config.preset]
  setConfig(partialConfig)     // same preset: merge over the current config. New preset: start from
                               // that preset's defaults + the given keys (tuning never carries over)
  setPointer(x, y, inside = true)   // CSS px relative to the canvas
  click(x, y)                  // burst, if config.clickBurst
  setFpsCap(fps)
  start()                      // requestAnimationFrame loop, honours fpsCap
  stop()                       // cancels the loop entirely
  resize()                     // sizes the backing store to clientWidth/Height × devicePixelRatio
  destroy()
}
```
